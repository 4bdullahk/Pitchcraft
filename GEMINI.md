\# Project Instructions



This is a React/Vite web application.



Before modifying code:



\- Understand the existing architecture.

\- Preserve existing functionality.

\- Do not rewrite working components unnecessarily.

\- Follow the existing design language.

\- Make all UI changes responsive.

\- Test the production build after major changes.



\## UI/UX



Use the UI/UX skill in:



.gemini/skills/ui-ux/SKILL.md



When asked to improve the interface, behave as a senior UI/UX designer and frontend engineer.



\## Important



Do not modify:



\- .env files

\- API keys

\- Firebase credentials

\- backend configuration



unless explicitly instructed.



Do not replace existing functionality with mock functionality.
